# Character sprites

`char_0.png` to `char_5.png` are based on the [MetroCity Free Top Down Character Pack](https://jik-a-4.itch.io/metrocity-free-topdown-character-pack)
by JIK-A-4 (CC0 1.0), as packaged by [Pixel Agents](https://github.com/pablodelucca/pixel-agents) (MIT).

Sheet layout: 112x96 px, 3 rows (row 0 = facing down, 1 = up, 2 = right; left = mirrored right),
7 frames of 16x32 per row: 0-2 walk, 3-4 typing, 5-6 reading.
